# Earntools Labs

这里汇集了我们的开发工具、产品分析平台，以及加密市场工具与实验项目。

## 项目入口

| 项目 | 用途 | 文档 |
| --- | --- | --- |
| [Tether](https://github.com/earntools-labs/tether) | AI CLI Agent 会话管理，支持持久会话与跨设备查看、接管 | [中文说明](https://github.com/earntools-labs/tether/blob/main/README.zh-CN.md) |
| [知迹 Zhiji](https://github.com/earntools-labs/zhiji) | 可自托管的产品分析、错误监控、热力图与会话回放平台 | [项目说明](https://github.com/earntools-labs/zhiji#readme) |
| [Blockchain Tools](https://github.com/earntools-labs/blockchain-exchange) | VS Code 扩展，提供行情、资金费率监控与交易工具 | [项目说明](https://github.com/earntools-labs/blockchain-exchange#readme) |
